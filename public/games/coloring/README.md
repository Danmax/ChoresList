# Coloring Adventures artwork

The six coloring pages were supplied by the user for this game:

- `treasure-jungle.png`: Jungle Treasure Chest Adventure.png (corrected replacement)
- `crocodile-creek.png`: Jungle Swamp Coloring Adventure.png (corrected replacement)
- `jungle-river.png`: Jungle Adventure Coloring Scene.png (corrected replacement)
- `jungle-friends.png`: Smiling Jungle Friends Coloring Scene.png
- `vine-swing.png`: Jungle Monkey Adventure Coloring Page.png
- `elephant-splash.png`: Joyful Elephant Jungle Waterfall Coloring Scene.png

The imported drawings are resized to 1280 pixels wide and stored as optimized
PNG files. Their outlines remain the top layer during coloring and export.
Scene IDs and asset paths live in `lib/coloring.ts`.
