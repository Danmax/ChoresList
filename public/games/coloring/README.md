# Coloring Adventures artwork

The three coloring pages were supplied by the user for this game:

- `treasure-jungle.png`: Monkey and Jaguar Treasure Adventure (1).png
- `crocodile-creek.png`: Crocodile and Monkey Jungle Adventure.png
- `jungle-friends.png`: Smiling Jungle Friends Coloring Scene.png

The imported drawings are resized to 1280 pixels wide and stored as optimized
PNG files. Their outlines remain the top layer during coloring and export.
Scene IDs and asset paths live in `lib/coloring.ts`.
