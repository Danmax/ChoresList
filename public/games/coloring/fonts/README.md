# Coloring lettering fonts

Bundled from the official https://github.com/google/fonts repository.
Fonts load from this app; runtime lettering does not contact Google Fonts.

- bangers.ttf: Bangers, ofl/bangers (SIL Open Font License)
- pacifico.ttf: Pacifico, ofl/pacifico (SIL Open Font License)
- marker.ttf: Permanent Marker, apache/permanentmarker (Apache License 2.0)
- stencil.ttf: Black Ops One, ofl/blackopsone (SIL Open Font License)
- rye.ttf: Rye, ofl/rye (SIL Open Font License)
- fredoka.ttf: Fredoka variable, ofl/fredoka (SIL Open Font License)

The accompanying OFL and LICENSE files contain the copyright notices and terms.
Names prefixed with “Coloring” are CSS family aliases; the font files are unmodified.
