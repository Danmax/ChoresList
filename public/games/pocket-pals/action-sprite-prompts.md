# Action sprite sheets

Generated with the built-in imagegen tool using each original character as an
identity reference. Alpha is preserved. Each sheet has three columns:
sleeping, eating, playing. The room selects the relevant column during an activity.
These are distinct action poses; room CSS supplies the gentle motion.

### dog-actions-v1.png

Use case: stylized-concept. Asset type: Pocket Pals transparent character sprite sheet. Input image: reference for the dog's exact character identity, colors, fur markings, face and painterly cute anime rendering. Create one landscape sprite sheet with exactly THREE evenly sized square cells side by side, no borders: LEFT sleeping curled up with closed eyes; CENTER eating a small dumpling held near mouth; RIGHT playing happily with a little ball and lifted paws. Each cell contains the same complete dog character, centered with equal scale and generous empty transparent padding, all parts within its own third of the canvas. Preserve identity and colors from reference. Real transparent background, no scene, no labels, no letters, no watermark. Sheet aspect ratio 3:1, clean isolated cutout silhouettes.
